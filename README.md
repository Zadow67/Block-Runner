# Block Runner

Block Runner is a simple runner game where you control a block, avoid obstacles, and collect points.

This is my first project made with Unity. I made it to learn the basics of Unity and game development.

## How to Play

* Use the left and right arrow keys to move.
* Avoid obstacles.
* Collect points as you play.
* Try to get the highest score you can.

## Controls

* **Left Arrow:** Move left
* **Right Arrow:** Move right

## How to Run

1. Download the game ZIP file.
2. Extract the ZIP file.
3. Open the extracted folder.
4. Run `Block Runner.exe` to play.

## Made With

* Unity
* C#
